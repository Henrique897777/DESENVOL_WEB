Web semâtica

A web semântica é uma extenção da web atual, onde a informação possui sinificado e permite que computadores e pessoas possam trabalhar em conjunto. As tags da web semaântica ajudam od mecanismos de busca na tarefa de criar repositorios e recuperar informações as principais tags são: <,header>,<,nav>, <,main>, <,section>, <,article>, <,aside> e <,footer>.

Neste exemplo estamos usando a web semântica em todo o documento html.
