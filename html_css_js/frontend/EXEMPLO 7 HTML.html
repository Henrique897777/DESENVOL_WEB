Exemplo 7 HTML - Uso das tags <ol> ,<ul> e <li>

As tags <ol>,<ul> representão listas em html, e são utilizadas para as mais diversas finalidades. A <ol> representa uma lista ordenada ja a tag <ul> representa uma lista não ordenada.

Em ambas as listas para representr os elementos da lista usamos a tag <li>

Além disso, estas listas podem conter outras lista de forma alinhadas.

Etapas para Desenvolver um Site(Lista Ordenada)

  1. PLANEJAMENTO
    1. Defir o objetivo do site
    2. Indentificar o público alvo
    3. Criar um mapa so site(site map)
  2. DESIGN
    1. Criar wireframes e protótipos
    2. Definir uma aleta de cores
    3. Dsesenvolver o layout no figma ou adobe XD
  3. DESINVOLVIMENTO
    1. Configuara o ambiente de desenvolvimento
    2. Codificar o front-end (html, css e JavaScript)
    3. Implementar o back-end(Node.js, PHP, C#,Java)
  4. TESTE
    1. Testar a responsividade e diferentes dispositivos
    2. Realizar testes de usabilidade
    3. Corrigir os bugs indentificados
  5. PUBLICAÇÃO
    1. Escolher um provedor de hospedagem
    2. Configuara o dominio SSL
    3. Fazer o deploy do site
