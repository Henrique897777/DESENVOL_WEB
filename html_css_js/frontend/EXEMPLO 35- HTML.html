EXEMPLO 35 - Boostrap Cores Contextuais

O bootstap utiliza um sistema de cores contextualizadas para facilitar a marcção e a estilização de elementos com base em seu significado ou proposito. Essas classes de cores são usadas para dar significado visual aos elementos html. Geralmente utilizamos essas cores em botões, alertas, barras de navegação e outros elementos de interface de usuarios

As cores contextuias mais utililizadas são

Esse texto aparece na cor mais fechada, escura e deriva do cinza

Esse texto representa perigo. Geralmente esta vermelho

Esse texto representa atenção

Esse texto representa informações
