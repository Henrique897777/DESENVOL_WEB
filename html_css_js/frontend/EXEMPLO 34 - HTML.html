Exemplo 34 bootstrap

O bootstrap é um framework front-end que fornece componentes para facilitar a criação de sites responsivos por desenvolvedores de aplicações

Coontainer

Os containers são elements de layout mais básico do bootsstrap e são obrigatorios ao usar o sistema de grade padrão desse framework. Eles são jusados para conter , preencher e as vezes centralizar elementos de conteudo html

Oara utilizar containers com bootstrap, temos duas opções: o seletore de classe container e o container-fluid. Em ambos os casos você terá opções de alinhamento personalizado.Quando usamos o seletor de classe container ele delimita larguras fixas no documento html, centralizando

Uso container-fluid

Nesta div estamos usando o container- fluid, observe que ele esta ocupando a tela toda. não adotando margerns lateris como o exemplo acima que usa apenas o seletor container.
