estrutura de um documento hmtl

a estrutura de um documento html e definida pela declaração DOCTYPE HTML e elas tags estruturante, head e body.

tag head

a tag head é utilizada para configurações do navegador e consequentemente para configurações do documento html, as informações contidas nesta tag não visiveis, com exceção do titulo que ficara visivel no topo da página.

tag body

a tag body é utilizada para exibir informações sobre os usúarios, tudo que estiver dentro desta tag ficara visivel.

nesta tag podemos ter outras tags que serão renderizadas pelo navegador.

tag html.

a tag html é a tag principal do documento html, ela é a tag raiz que contém as outras tags que possibilitam a interpetação do documento html.

intrução DOCTYPE

a intrução DOCTYPE indica ao navegador qual a versão do html que vamos utilizar, ela não é uma tag html, como dito ela é uma instrução que indica a versão atual do html, nesta vamos usar o html 5.
