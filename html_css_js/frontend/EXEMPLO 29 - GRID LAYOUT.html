O que é o GRID LAYOUT

O Grid Layout é bidimencional, permintindo que o desenvolvedor possa separar o layout da pagina em linhas e colunas, diferenciando do flebox que é unidimencional e uqe ordena os elementos somente em linha.

Flexbox ou Grid Layout

O Flexbox e o Grid Layout podem ser usados em conjuntos. Você pode usar o Flexbox a elementos que estejam udando o layout em grade. Aproveitando as duas técnicas.

A escolha entre o Flexbox e o Grid Layout não se trata em substituir o outro, mas sim de entender as necessidades especificas do seu layout e escolher a técnica que melhor atenda as suas necessidades.
